# LocalMonkey

Simple external IDE solution for \*monkey userscripts.

Made in frusttration with Tampermonkey's in-browser IDE.

## How to use
Run the script, install the userscript.user.js, and modify it to match your target URL and require `http://127.0.0.1:3000/script/whateveryounamedit.js`.</br>
